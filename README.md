# 📝 Todo List Web App

A simple and visually appealing Todo List application built using **HTML, CSS, and JavaScript**. This app allows users to add, delete, and store tasks using **localStorage**, ensuring tasks persist even after refreshing the page.

---

## 🚀 Features

- ✅ Add new todos  
- ❌ Remove todos  
- 💾 Persistent storage using `localStorage`  
- ⚡ Fast and responsive UI  
- 🎨 Modern UI with animations  
- 📱 Mobile-friendly layout  
- 🔄 Auto-focus input field on load  
- ⚠️ Duplicate todo prevention  
- 📭 Empty state message when no todos exist

## ⚙️ How It Works

1. Enter a task in the input field  
2. Click **"Add Todo"**  
3. Task is:
   - Added to the list  
   - Saved in `localStorage`  
4. On reload:
   - Tasks are automatically loaded  
5. Click **×** to remove a task  

---

## ▶️ How to Run

1. Download or clone the repository  
2. Open `index.html` in your browser  
3. Start adding your todos 🎉
